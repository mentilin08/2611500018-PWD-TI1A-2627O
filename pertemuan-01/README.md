1. Konsep Dasar Pemrograman Web<br>
Menurut saya, konsep dasar pemrograman web adalah suatu proses membangun dan membuat suatu web menggunakan teknologi yang sesuai dengan kebutuhan aplikasi.<br><br>
2. Arsitektur Klien-Peladen<br>
klien dan peladen adalah suatu media yang memiliki peran sebagai klien(client) dan peladen (server).<br>
Secara sederhana klien mengirimkan permintaan dan peladen menerima permintaan dari klien.<br><br>
3. HTTP Request dan Response<br>
- HTTP Request, yaitu permintaan yang dikirimkan oleh klien kepada peladen<br>
- HTTP Response, yaitu respons yang dikirimkan oleh peladen kepada klien setelah permintaan diterima
dan diproses.<br><br>
4. HTML, CSS, JavaScript, PHP, MySQL<br>
- HTML untuk menyusun struktur dan konten halaman web.<br>
- CSS untuk menyusun struktur dan konten halaman web.<br>
- JavaScript untuk menambahkan perilaku dan interaksi pada sisi klien.<br>
- PHP untuk untuk melakukan pemrosesan pada sisi peladen.<br>
- MySQL untuk menyimpan dan mengelola data aplikasi.<br><br>
5. Hubungan Antarteknologi<br>
bersifat saling terhubung, saling berkaitan dan saling bertanggung jawab dalam membentuk suatu sistem.
